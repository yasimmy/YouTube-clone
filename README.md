# 🎬 YouTube - Современный видеохостинг

Полнофункциональная платформа для размещения и просмотра видео с современным дизайном, 3D эффектами и расширенными возможностями.

![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Основные возможности

### 🎥 Видео и контент
- **Загрузка и управление видео** - Загружайте видео, настраивайте приватность, добавляйте описания и теги
- **Кастомный видеоплеер** - YouTube-like плеер с расширенными возможностями
  - Режим театра и полноэкранный режим
  - Мини-плеер при прокрутке страницы
  - Горячие клавиши (Пробел = пауза, ←→ = перемотка, ↑↓ = громкость, M = без звука, F = полноэкран, T = театр)
  - Настройки скорости воспроизведения (0.25x, 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x)
  - Выбор качества видео (auto, 1080p, 720p, 480p, 360p)
  - Автовоспроизведение следующего видео
  - Индикатор буферизации
  - Превью времени при наведении на прогресс-бар
- **Алгоритм рекомендаций** - Умная система подбора видео на основе просмотров и предпочтений
- **Плейлисты** - Создавайте публичные, приватные и непубличные плейлисты с автовоспроизведением
- **История просмотров** - Автоматическое сохранение истории с возможностью возобновления с места остановки
- **Таймкоды в комментариях** - Кликабельные таймкоды (например, `0:02`, `1:23:45`) для быстрой перемотки видео

### 👤 Пользователи и каналы
- **Профили каналов** - Полноценные профили с баннерами, аватарами и описаниями
- **Рамки аватаров** - 20+ уникальных рамок (золотые, серебряные, сезонные, официальные)
  - Расширяемый/сворачиваемый список в настройках
  - Официальные рамки только для официальных каналов
- **Значки** - Система значков для достижений и статусов (staff, verified, premium, partner, creator, сезонные)
- **Подписки** - Подписывайтесь на каналы и следите за новыми видео
- **Поиск пользователей** - Расширенный поиск с отображением значков и статусов

### 💬 Социальные функции
- **Комментарии** - Комментируйте видео, отвечайте на комментарии, лайкайте
  - Кликабельные таймкоды для перемотки видео
  - Закрепление комментариев автором
  - Отметка "Понравилось автору"
  - Удаление комментариев
- **Лайки и дизлайки** - Оценивайте контент
- **Расширенное "Поделиться"**
  - Поделиться в соцсетях (VK, Telegram, Twitter)
  - QR-код для быстрого доступа
  - Поделиться с временной меткой (timestamp)
  - Короткие ссылки
  - Код для встраивания (iframe)

### 🔒 Безопасность
- **Двухфакторная аутентификация (2FA)** - Защита аккаунта через Google Authenticator
  - QR-код для настройки
  - Резервные коды для восстановления
  - Обновление резервных кодов
  - Обязательный ввод кода при каждом входе
- **История входов** - Просмотр всех входов в аккаунт с информацией об устройстве, IP и местоположении
- **Управление сессиями** - Просмотр и завершение активных сессий на разных устройствах
- **Смена пароля** - Безопасная смена пароля с проверкой старого пароля
- **Защита от атак** - Защита от DDoS и SQL-инъекций
- **Санитизация данных** - Очистка пользовательского ввода

### 🎨 Дизайн и UX
- **3D дизайн** - Интерактивные 3D эффекты по всему сайту
  - 3D трансформации при наведении
  - Глубинные тени и свечения
  - Плавные анимации
  - 3D эффекты для карточек, кнопок, видеоплеера
- **Сезонные эффекты** - Автоматическая смена темы в зависимости от времени года
  - Осенние эффекты (листья, тыквы)
  - Зимние эффекты (снег, гирлянды)
  - Весенние эффекты (цветы, лепестки)
  - Летние эффекты (волны, солнце)
- **Темная/светлая тема** - Переключение между темами
- **Адаптивный дизайн** - Оптимизация для всех устройств
- **Голосовой поиск** - Поиск видео голосом

### 🎁 Геймификация
- **Виртуальная валюта** - Зарабатывайте валюту за активность
- **Система достижений** - Получайте значки за различные действия
- **Сезонные события** - Специальные события и награды по сезонам
- **Адвент-календарь** - Ежедневные награды в декабре

### 🛠️ Творческая студия
- **Аналитика** - Статистика просмотров, лайков, комментариев
- **Управление видео** - Редактирование, удаление, изменение приватности
- **Управление комментариями** - Модерация комментариев под вашими видео
- **Управление плейлистами** - Создание и редактирование плейлистов
- **Доходы** - Отслеживание доходов (в разработке)

### 👨‍💼 Админ-панель
- **Управление пользователями**
  - Просмотр всех пользователей
  - Поиск пользователей (по имени, email, ID)
  - Блокировка/разблокировка аккаунтов
  - Выдача предупреждений
  - Заморозка/разморозка аккаунтов
  - **Полное удаление аккаунта** - Удаление пользователя и всех связанных данных (видео, комментарии, подписки, история и т.д.)
  - Сброс паролей (включая админа)
  - Назначение ролей администраторов
  - Выдача значков
- **Управление видео** - Модерация контента, удаление видео
- **Обработка жалоб** - Система жалоб с шаблонами решений
- **Управление сезонами** - Изменение текущего сезона
- **Логи и статистика** - Детальная статистика и логи активности
- **Обратная связь** - Просмотр и обработка отзывов пользователей

### 📱 Дополнительные функции
- **Уведомления** - Система уведомлений о новых видео, комментариях, подписках, наградах
- **Избранное** - Сохраняйте понравившиеся видео
- **Поиск** - Расширенный поиск с фильтрацией
- **Справка** - Подробная справка по использованию платформы
- **Обратная связь** - Форма для отправки отзывов и предложений
- **История изменений** - Changelog с фильтрацией по типам обновлений

## 🛠️ Технологии

- **Next.js 14** - React фреймворк с App Router
- **TypeScript** - Строгая типизация
- **SCSS Modules** - Модульная стилизация
- **Framer Motion** - Плавные анимации
- **Zustand** - Управление состоянием
- **React Hook Form** - Работа с формами
- **React Player** - Видео плеер
- **bcryptjs** - Хеширование паролей
- **otplib** - Двухфакторная аутентификация
- **date-fns** - Работа с датами
- **react-hot-toast** - Уведомления

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone <repository-url>

# Установите зависимости
npm install

# Запустите dev сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
